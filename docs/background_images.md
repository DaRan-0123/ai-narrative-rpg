# 游戏地点背景图生成清单

> 本文件记录游戏中所有有地名的地点，每个地点需要一张 AI 生成的背景图。
> 生成后图片保存到 `assets/backgrounds/` 目录。
> 当前使用 pollinations.ai 免费方案开发，上线后迁移到阿里云百炼。

---

## 生成规范

### 通用 Prompt 模板
```
[地点类型], [世界观风格], [时间/天气], [氛围描述], 
2D game background, pixel art style, side-scrolling perspective,
no characters, no text, atmospheric lighting, detailed environment
```

### 输出规格
- 分辨率：1280×720 或 1920×1080
- 风格：像素风 / HD-2D（歧路旅人风格）
- 无人物、无文字
- 氛围与当前游戏时间/天气匹配
